# Byways 06: Emulator Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Emulator Lab: a separate page that runs files the user owns in four pinned, vendored emulators (js-dos, EmulatorJS, v86, Ruffle), with a BIOS shelf, a Storage & saves panel, offline caching and an in-app Licenses screen.

**Architecture:** `tools/vendor.js` copies only the needed files of exact-version npm packages (plus the v86 BIOS files, checked by SHA-256) into `vendor/<pkg>@<ver>/`, and `tools/build.js` copies `vendor/` and `src/lab/` into the PWA and Android outputs. `lab/index.html` is a top-level page: it detects the system from the file extension, asks the user to confirm, then opens one same-origin runner iframe per session and hands it the `File` by `postMessage` (`lab/runner-host.js`). The Lab tells the main app that it is running, and takes a "stop" from it, over a same-origin `BroadcastChannel`, so lean-back pauses and the voice "stop" works without the Lab ever holding a reference to the app's window.

**Tech Stack:** ES2022 modules with no bundler; js-dos 8.5.3, @emulatorjs/emulatorjs 4.2.3 plus seven non-threaded core packages at 4.2.3, v86 0.5.473, @ruffle-rs/ruffle 0.7.1, fflate 0.8.3; `node:test`; `@playwright/test@1.63.0` with Chromium.

**Spec:** `docs/superpowers/specs/2026-11-11-byways-design.md` (§11, §16, §15.2, §13.2, §6.5). Shared contract: `docs/superpowers/plans/2026-11-11-byways-00-overview.md`. Research: `docs/superpowers/specs/byways-research/emulators.md`, `platform-shells.md`, `critic.md`.

## Global Constraints

- Everything in the overview's "Global constraints (every plan)" applies. These are the ones that bite this plan:
- "The Lab is for files you own. Byways ships no games, ROMs or BIOS files. The only exception is v86's open-source SeaBIOS and VGABIOS." Test files are generated by the tests and never committed as binaries.
- "Third-party code. It is pinned and vendored at build time, with integrity checks: the npm lockfile, plus SHA-256 values in `versions.json` for the v86 BIOS files. Byways never loads code from a CDN at runtime."
- "Emulators are exact-version `devDependencies`, so `npm ci` checks their integrity." Vendor only the non-thread core `.data` files plus `reports/<core>.json`.
- "Lab pages also add `'wasm-unsafe-eval' blob:` to `script-src` and `blob:` to `worker-src`."
- Plan decision on top of that CSP: `lab/index.html` also adds `'self'` to `frame-src` (it frames its own runner pages), and `dos.html` and `console.html` also add `blob:` to `connect-src` (js-dos fetches the game from a `blob:` URL and EmulatorJS fetches the BIOS ZIP from one). No other page changes.
- "No cross-origin isolation anywhere (no COOP/COEP). So PSP, `dosbox_pure`, N64 and all threaded cores are out of v1."
- "Separate page. The Lab is a separate top-level page (`lab/index.html`), not a frame inside the main app." The app opens it with `rel="noopener"`.
- "Stable file id. Each file's id is the SHA-256 of its name, size and first 4 MiB. It is used for the js-dos `fsChanges.urlToKey`, `EJS_gameName` and the v86 state keys."
- "Lab safety. … A visible **Exit** button and the voice command "stop" always work, because js-dos captures Esc in fullscreen." "Closing the runner removes the iframe."
- "Large files. Above about 500 MB on a phone, Byways warns before loading. v86 streams files of 256 MB or more lazily."
- `lab/pc.html`: "128 MB of memory on desktop and 64 MB on phones (adjustable). An on-screen keyboard drawn by Byways. `save_state()` goes to IndexedDB."
- `lab/flash.html`: "Script access and networking turned off."
- "It asks for `navigator.storage.persist()` before the first save. After each session it removes js-dos `caches/bundles/blob_*` entries."
- "Offline. The service worker caches each emulator's files the first time they are used. For EmulatorJS this includes `reports/<core>.json`, or core caching breaks."
- Lean-back "pauses on: … the Lab running". "After a game or embed, it resumes only on an explicit **resume**."
- "No ads or payments in the Lab, ever, because some cores have non-commercial licences."
- Do not set `EJS_DEBUG_XX` (it contacts a remote host and turns off core caching).

## Review Focus

1. **Exit while a runner is still loading or hung.** A user who picks the wrong file presses Exit before the emulator is up, or the emulator never answers. Exit must remove the iframe within its 2-second grace period and bring back the picker. Pinned by Task 7, test `Exit works while the runner is still loading`.
2. **Second launch with no network.** Someone plays a NES game once, then opens the Lab on a train. The core `.data` file and its `reports/<core>.json` must come from the service worker cache, or EmulatorJS re-downloads the core and fails. Pinned by Task 12, test `a console game starts offline after one online run`.
3. **Odd file names.** Upper-case extensions (`MARIO.SFC`), double extensions (`game.nes.zip`), no extension (`README`) and a trailing dot (`x.`). The user expects the right system, or an honest "pick one", never a crash. Pinned by Task 3, test `detectSystem handles odd names`.
4. **Messages from other windows.** Another project on the shared `github.io` origin, or any other window, posts a look-alike message. A runner must act only on messages from its own parent on its own origin. Pinned by Task 4, test `connectRunner ignores messages from other sources and origins`.
5. **The tab closed in the middle of a DOS session.** The post-session prune never runs, so a full `blob_*` copy of the game stays in OPFS and the next sessions add more. The Lab must prune leftovers when it opens. Pinned by Task 8, test `leftover blob_ bundles are pruned when the Lab opens`.

### Task 2: Vendor tool

**Files:**
- Create: `tools/vendor.js`
- Test: `tests/unit/vendor.test.js`

**Interfaces:**
- Consumes: `src/versions.json` (Task 1).
- Produces:
  - `VENDOR_PACKAGES(versions) → Array<{name, version, dir, files: string[]}>`. `dir` is `<name>@<version>` (for example `@emulatorjs/core-snes9x@4.2.3`). A `files` entry is an exact path, a directory ending in `/` (copied whole), or a single-segment pattern with one `*`.
  - `LICENCE_NOTES: Object<string, {name, licence, source, note?}>`, keyed by npm name plus `'seabios'`, `'atkinson'` and `'byways'`.
  - `copyPackage({root, pkg}) → Promise<Array<{path, bytes}>>`, copying `root/node_modules/<name>/…` to `root/vendor/<dir>/…`.
  - `fetchBios({root, versions, fetchImpl}) → Promise<Array<{path, bytes}>>`, writing `vendor/v86@<ver>/bios/<file>`.
  - `vendor({root, fetchImpl = fetch}) → Promise<Manifest>`, where `Manifest = {v:1, generatedAt, packages: [{name, version, dir, licence, bytes, files: [{path, bytes}]}]}`, written to `vendor/manifest.json`. The BIOS files are listed under the `v86` entry as `bios/seabios.bin` and `bios/vgabios.bin`.
  - Run as a script (`npm run vendor`), it calls `vendor({root: process.cwd()})` and prints `vendor: <n> packages, <MB> MB`.

- [ ] **Step 1: Write the failing tests**

```js
// tests/unit/vendor.test.js — helpers: mkRoot() makes a temp dir with fs.mkdtempSync;
// put(root, rel, text) writes a file, creating folders.
import { VENDOR_PACKAGES, LICENCE_NOTES, copyPackage, fetchBios } from '../../tools/vendor.js';
const versions = JSON.parse(fs.readFileSync('src/versions.json', 'utf8'));

test('VENDOR_PACKAGES lists only the needed files', () => {
  const p = Object.fromEntries(VENDOR_PACKAGES(versions).map((x) => [x.name, x]));
  assert.equal(Object.keys(p).length, 12);
  assert.deepEqual(p['js-dos'].files, ['dist/js-dos.js', 'dist/js-dos.css', 'dist/emulators/emulators.js',
    'dist/emulators/wdosbox.js', 'dist/emulators/wdosbox.wasm', 'dist/emulators/wdosbox-x.js',
    'dist/emulators/wdosbox-x.wasm', 'dist/emulators/wlibzip.js', 'dist/emulators/wlibzip.wasm']);
  assert.deepEqual(p['@emulatorjs/emulatorjs'].files, ['data/']);
  assert.deepEqual(p['@emulatorjs/core-snes9x'].files, ['snes9x-wasm.data', 'snes9x-legacy-wasm.data', 'reports/snes9x.json']);
  assert.equal(p['@emulatorjs/core-snes9x'].dir, '@emulatorjs/core-snes9x@4.2.3');
  assert.deepEqual(p.v86.files, ['build/libv86.mjs', 'build/v86.wasm', 'build/v86-fallback.wasm']);
  assert.deepEqual(p['@ruffle-rs/ruffle'].files, ['ruffle.js', 'core.ruffle.*.js', '*.wasm']);
  assert.deepEqual(p.fflate.files, ['esm/browser.js']);
  for (const x of Object.values(p)) for (const f of x.files) assert.doesNotMatch(f, /thread/);
});

test('LICENCE_NOTES flags the non-commercial cores', () => {
  assert.equal(LICENCE_NOTES['@emulatorjs/core-snes9x'].note, 'Non-commercial licence');
  assert.equal(LICENCE_NOTES['@emulatorjs/core-genesis_plus_gx'].note, 'Non-commercial licence');
  assert.equal(LICENCE_NOTES['js-dos'].licence, 'GPL-2.0');
  assert.equal(LICENCE_NOTES['@emulatorjs/emulatorjs'].licence, 'GPL-3.0');
  assert.equal(LICENCE_NOTES.v86.licence, 'BSD-2-Clause');
  assert.equal(LICENCE_NOTES.seabios.licence, 'LGPL-3.0');
  assert.equal(LICENCE_NOTES['@ruffle-rs/ruffle'].licence, 'MIT OR Apache-2.0');
  for (const n of Object.values(LICENCE_NOTES)) assert.match(n.source, /^https:\/\//);
});

const ruffle = { name: '@ruffle-rs/ruffle', version: '0.7.1', dir: '@ruffle-rs/ruffle@0.7.1',
  files: ['ruffle.js', 'core.ruffle.*.js', '*.wasm'] };
function ruffleRoot(installed = '0.7.1') {
  const root = mkRoot(), m = 'node_modules/@ruffle-rs/ruffle/';
  put(root, m + 'package.json', JSON.stringify({ version: installed, license: 'MIT OR Apache-2.0' }));
  put(root, m + 'ruffle.js', 'a'); put(root, m + 'core.ruffle.abc.js', 'bb');
  put(root, m + 'x.wasm', 'ccc'); put(root, m + 'notes.md', 'no');
  return root;
}

test('copyPackage copies only matches and reports sizes', async () => {
  const root = ruffleRoot();
  const files = await copyPackage({ root, pkg: ruffle });
  assert.deepEqual(files, [{ path: 'core.ruffle.abc.js', bytes: 2 }, { path: 'ruffle.js', bytes: 1 }, { path: 'x.wasm', bytes: 3 }]);
  assert.equal(fs.existsSync(path.join(root, 'vendor/@ruffle-rs/ruffle@0.7.1/notes.md')), false);
});

test('copyPackage rejects a wrong installed version', async () => {
  await assert.rejects(copyPackage({ root: ruffleRoot('0.7.0'), pkg: ruffle }),
    /@ruffle-rs\/ruffle is 0\.7\.0, expected 0\.7\.1\. Run npm ci\./);
});

test('copyPackage rejects a pattern with no match', async () => {
  const root = ruffleRoot();
  fs.rmSync(path.join(root, 'node_modules/@ruffle-rs/ruffle/x.wasm'));
  await assert.rejects(copyPackage({ root, pkg: ruffle }), /@ruffle-rs\/ruffle has no file matching \*\.wasm/);
});

test('fetchBios downloads from the pinned commit and checks SHA-256', async () => {
  const body = Buffer.from('bios');
  const sha = crypto.createHash('sha256').update(body).digest('hex');
  const v = { v86: { version: '0.5.473', commit: 'c'.repeat(40), bios: { 'seabios.bin': sha, 'vgabios.bin': sha } } };
  const urls = [];
  const fetchImpl = async (u) => { urls.push(u); return new Response(body); };
  const root = mkRoot();
  await fetchBios({ root, versions: v, fetchImpl });
  assert.deepEqual(urls, ['https://raw.githubusercontent.com/copy/v86/' + 'c'.repeat(40) + '/bios/seabios.bin',
    'https://raw.githubusercontent.com/copy/v86/' + 'c'.repeat(40) + '/bios/vgabios.bin']);
  assert.equal(fs.readFileSync(path.join(root, 'vendor/v86@0.5.473/bios/seabios.bin'), 'utf8'), 'bios');
  urls.length = 0;
  await fetchBios({ root, versions: v, fetchImpl });          // good files already there
  assert.deepEqual(urls, []);
  const bad = { v86: { ...v.v86, bios: { 'seabios.bin': '0'.repeat(64), 'vgabios.bin': sha } } };
  await assert.rejects(fetchBios({ root: mkRoot(), versions: bad, fetchImpl }), /seabios\.bin SHA-256 mismatch/);
});
```
