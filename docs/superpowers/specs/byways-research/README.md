# Byways research notes (2026-11-11)

These notes back the Byways design spec (`../2026-11-11-byways-design.md`).
Eight researchers each covered one topic, and a critic then looked for contradictions and gaps.

Each fact carries a status:

- **verified**: checked against package contents, source code or a live request.
- **likely**: strong indirect evidence.
- **unverified**: plausible but not checked.
- **false**: checked and wrong.

The research machine could not reach most content hosts (archive.org, Wikipedia, jsDelivr and others), so many web facts rest on search results. Each note lists its own open risks. The spec's "Still to verify" section and the `byways-probe.yml` workflow exist to close those gaps.

The evidence text was left out to keep the notes short. Paths that point to a temporary scratchpad no longer exist.
