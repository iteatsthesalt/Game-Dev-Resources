8-Way Sprite Rig

A hidden 3D skeleton drives the game. Each frame, the sprite picks its row from the angle between the character and the camera, and its column from the skeleton's clip time. Attachments ride on projected 3D bones.

Baked atlas · 8 directions × 8 walk frames · 32×48 px cells

Every cell was rendered from the same skeleton and walk cycle by a virtual camera at that row's angle, then pixel-thresholded and outlined. With mirroring on, rows 225°–315° are never sampled: the runtime flips rows 135°–45° instead and shifts the frame by half a cycle so the stride stays on the correct leg.

Runtime wiring

// Runs every frame, after the 3D skeleton has animated.
function spriteFor(skel, camYaw, state) {
  const rel = wrap360(skel.facingYaw - camYaw); // 0° = we see its back
  state.dir = pickDir(rel, state.dir, HYST);    // 0..7, sticky near edges
  let frame = Math.floor(skel.clipTime * FRAMES); // clipTime is 0..1
  let row = state.dir, flip = false;
  if (MIRROR && row > 4) {                      // 5,6,7 reuse 3,2,1
    row = 8 - row; flip = true;
    frame = (frame + FRAMES / 2) % FRAMES;      // swap the leading leg
  }
  return { row, frame, flip };
}

function pickDir(rel, cur, hyst) {
  const snap = Math.floor((rel + 22.5) / 45) % 8;
  if (cur == null) return snap;
  const off = Math.abs(wrap180(rel - cur * 45));
  return off <= 22.5 + hyst ? cur : snap;     // only leave past the margin
}

// Attachments: project the 3D bone with the SNAPPED angle and frame,
// so the prop sticks to the drawn hand instead of drifting.
const hand = project(skel.boneAt("hand.R", frame / FRAMES), state.dir * 45);

How the pieces connect

  1. The skeleton is the truth. Movement, animation state, hitboxes and bone positions all live on the 3D rig. The sprite never drives gameplay.
  2. Row from angle. Subtract the camera's yaw from the character's yaw, then quantize to 45° sectors. Hysteresis keeps the row from flickering when the angle sits on a sector edge.
  3. Column from clip time. The atlas columns are the same clip baked at even steps, so floor(t × frames) keeps sprite and skeleton in lockstep through blends and speed changes.
  4. Props from bones. Project the hand bone to screen and draw the prop there. Compare its depth to the chest to decide whether it draws behind or in front of the sprite.
  5. Mirroring is free art. A left-right flip of a walk is the same walk half a cycle later, so 5 baked rows cover all 8.
